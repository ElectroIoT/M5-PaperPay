Install in your browser

Flash M5PaperPay onto an M5Stack M5Paper from Chrome or Edge on a computer - no tools to install.

  1. Connect the M5Paper with a USB-C data cable and switch it on.
  2. Press Install and choose the serial port (CH9102 / USB-Enhanced-SERIAL).
  3. Wait about 3 minutes (the image includes the web dashboard). Do not unplug.
  4. On first start join the M5PaperPay-Setup Wi-Fi on your phone and enter your Wi-Fi and UPI ID.
Your browser does not support Web Serial. Use Chrome or Edge on a desktop computer. Web Serial needs HTTPS - open this page from GitHub Pages.

A fresh install erases the M5Paper's saved settings (Wi-Fi, UPI ID, payment log).

Other ways to install: see the flashing guide.
